# Prolite

A mobile-first social app prototype with a 110 MB storage manager built as a single-page, front-end app.

## Features

- Dark, creator-focused UI inspired by the mockup
- Responsive layout for mobile screens
- Video feed with creator card and actions
- Create, chat, wallet, and discover sections
- 110 MB storage quota tracker with local persistence
- Add media upload simulation and storage clear/reset actions

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 3000
```

Then visit:

```text
http://localhost:3000
```

## Files

- `index.html` — app structure
- `styles.css` — styling and layout
- `app.js` — storage logic and interactions
